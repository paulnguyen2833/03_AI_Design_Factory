# AI Memory — v0.1

Đây là bộ nhớ kiến thức riêng của ADF. Chỉ promote một kết luận vào đây khi có evidence từ prompt, experiment, issue, production hoặc marketplace.

## Quy tắc ghi nhớ

- Mỗi memory có phạm vi áp dụng rõ ràng.
- Phân biệt `Hypothesis`, `Observed`, `Validated`, `Deprecated`.
- Ghi nguồn evidence và ngày kiểm chứng.
- Kết luận mâu thuẫn không bị xóa; tạo version mới và archive kết luận cũ.
- Không lưu secret, credential hoặc dữ liệu cá nhân.
