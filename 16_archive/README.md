# Archive

Không xóa artifact nghiệp vụ. Khi ngừng dùng:

1. Đặt status thành `Archived` hoặc `Superseded`.
2. Ghi lý do và Decision ID.
3. Chuyển nguyên artifact vào thư mục con theo năm, ví dụ `16_archive/2026/`.
4. Giữ nguyên ID; không tái sử dụng.

Git history là lớp bảo vệ bổ sung, không thay thế Archive.
